# TCP/IP Basics

## What Is TCP/IP?

TCP/IP is a collection of networking protocols used for communication between devices.

It is the foundation of communication across modern computer networks and the Internet.

---

## IP

IP stands for **Internet Protocol**.

IP is responsible for addressing and delivering packets between networks.

Example IPv4 address:

192.168.1.10

---

## TCP

TCP stands for **Transmission Control Protocol**.

TCP provides reliable, connection-oriented communication.

It helps ensure that data is delivered correctly and in the correct order.

---

## UDP

UDP stands for **User Datagram Protocol**.

UDP provides connectionless communication and has less overhead than TCP.

It can be useful when low overhead and speed are important.

---

## TCP vs UDP

| Protocol | Basic Characteristic |
|---|---|
| TCP | Reliable and connection-oriented |
| UDP | Connectionless and lower overhead |

---

## Learning Note

TCP/IP contains many protocols and concepts. This document covers only the basic concepts needed for beginner networking studies.
