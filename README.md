# Networking Basics Lab

This repository documents my practical learning and beginner-level labs related to computer networking.

The purpose of this repository is to build a strong foundation in networking concepts and develop practical troubleshooting skills.

---

## 🌐 Topics Covered

- Basic networking concepts
- LAN, WLAN and WAN
- Network devices
- IPv4 addressing
- Subnet masks
- Default gateway
- DHCP
- DNS
- TCP/IP fundamentals
- Ping testing
- Windows IP configuration
- Basic network troubleshooting
- Cisco Packet Tracer labs

## 🧪 Practical Labs

The repository includes beginner-friendly practical labs such as:

- Basic ping testing
- Checking IP configuration using `ipconfig`
- Testing network connectivity

- Basic network troubleshooting
